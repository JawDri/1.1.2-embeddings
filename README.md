## Get the code
- **Download:** the green **Code** button → **Download ZIP**, then unzip it.
- **Or clone:** `git clone https://github.com/JawDri/1.1.2-embeddings.git`

Keep the folder's name as it is: `setup.ps1` and `run.ps1` read the lesson number (1.1.2) from it.

## Run it
Everything is in [`code/README.md`](code/README.md): set up once (`setup.ps1` on Windows, a virtual environment on
Mac / Linux), then run the demos from the `code` folder.

## No API key needed
Everything in this lesson runs on your own computer, for free.
